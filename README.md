# Min Gym App v1.3

En privat träningsapp byggd med HTML, CSS och JavaScript.

## Nytt i v1.3

- Svart/vit design
- Versionsnummer under rubriken
- Fliknavigering med tydligare design
- Kortbaserad layout
- PWA-manifest
- Hemskärmsikon med muskelarm

## Funktioner

- Dagens pass
- Upplägg
- Historik
- PB/personbästa
- Lokal lagring i webbläsaren via LocalStorage
